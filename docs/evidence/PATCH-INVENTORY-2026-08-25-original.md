## Patch themes requiring migration/regression coverage

The filenames and existing tests establish these migration groups:

1. Runtime adapter and Pi session lifecycle (`pi-runtime-adapter*`, `pi-session*`).
2. Discord rendering and delivery fallback (`live-discord-renderer*`, message/interaction handling).
3. Restart recovery (`restart-notification*`, runtime/entrypoint wiring).
4. Extension binding and duplicate extension/MCP suppression (`extension-bindings*`, `extension-bridge.ts`, `pi-resource-loader.ts`).
5. Discord lifecycle, naming, access/configuration and long-running interactions (`discord-bot*`, `interaction-handler.ts`, `config.ts`).
6. Voice transcription (`voice-transcription.ts` and associated Discord wiring).
